# TJES Contingência v0.6 — protótipo

Publique `index.html` na raiz do GitHub Pages. A tela **Painel do dia** utiliza somente os registros locais e não acessa o Assyst. O registro usa a mesma chave local da v0.5, mas no domínio GitHub Pages não compartilha registros com o HTML aberto por arquivo.

**Somente dados fictícios:** o armazenamento local desta versão não é criptografado. Não use dados reais sem aprovação da TI e controles adequados.

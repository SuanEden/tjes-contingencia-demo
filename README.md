# TJES Contingência v1.1

Publique `index.html` na raiz do GitHub Pages. A tela **Painel do dia** utiliza somente os registros locais e não acessa o Assyst. O registro usa a mesma chave local da v0.5, mas no domínio GitHub Pages não compartilha registros com o HTML aberto por arquivo.

**Somente dados fictícios:** o armazenamento local desta versão não é criptografado. Não use dados reais sem aprovação da TI e controles adequados.


## Versão 1.1

- Compartilhamento do relatório diário em XML pelo compartilhamento nativo do dispositivo, quando disponível.
- Alternativa de download do XML e abertura do chat do Teams quando o navegador não suporta compartilhar arquivos.
- Mantém a estrutura original da tela Novo atendimento e os dados locais existentes.
- O envio pelo Teams continua exigindo confirmação do usuário; o navegador não envia mensagens automaticamente.

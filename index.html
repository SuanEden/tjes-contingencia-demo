Cópia de segurança

Os registros ficam neste navegador, sem senha e sem criptografia. Limpar os dados do navegador pode apagá-los. Faça cópias de segurança somente com dados fictícios durante os testes.

A restauração substitui os registros atuais. O backup desta versão é legível e não deve conter dados pessoais reais. Backups antigos criptografados exigem a senha anterior apenas para restauração.

Os scripts do modelo são incorporados ao programa e não contêm os nomes, CPFs e telefones de casos específicos do exemplo.

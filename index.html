Scripts e modelos de tratativas

Os modelos são exemplos da documentação enviada. Valide conteúdo, contatos e bases com a operação antes do uso oficial.

Cópia de segurança

Os registros ficam neste navegador, sem senha e sem criptografia. Limpar os dados do navegador pode apagá-los. Faça cópias de segurança somente com dados fictícios durante os testes.

A restauração substitui os registros atuais. O backup desta versão é legível e não deve conter dados pessoais reais. Backups antigos criptografados exigem a senha anterior apenas para restauração.

Os scripts do modelo são incorporados ao programa e não contêm os nomes, CPFs e telefones de casos específicos do exemplo.

▣ Base de conhecimento • Sugestões

Sugestões baseadas no resumo. Clique em uma sugestão para preencher a descrição. Se faltar informação, o sistema mostra o modelo para conferência.

Ao selecionar um modelo, o resumo e a descrição são ajustados juntos. O resumo muda automaticamente; só é solicitada confirmação quando a descrição preenchida será substituída. Nada é salvo sem clicar em Salvar atendimento.

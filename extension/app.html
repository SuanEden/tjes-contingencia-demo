Base de Conhecimento

Os modelos são exemplos da documentação enviada. Valide conteúdo, contatos e bases com a operação antes do uso oficial.

Novo conhecimento

O conhecimento ficará salvo neste navegador e poderá ser exportado em Importar e exportar dados. Não inclua dados pessoais ou credenciais.

Importar e exportar dados

Transfira seus registros entre navegadores ou guarde uma cópia local. O arquivo JSON contém dados legíveis e não é criptografado. Utilize somente dados autorizados para armazenamento local.

Exportar dados

Escolha o conteúdo que deseja salvar em um arquivo .json.

Importar dados

Selecione um arquivo exportado anteriormente. Você poderá escolher o que recuperar.

A importação substitui apenas as categorias selecionadas e solicita confirmação. Exporte os dados atuais antes de importar outros. A base padrão do aplicativo continua incluída no código.

Arquivos antigos contendo somente chamados (inclusive versões criptografadas) também podem ser importados.

▣ Base de conhecimento • Sugestões

Se houver um resumo, mostra modelos compatíveis. Sem resumo, mostra seus modelos recentes ou sugestões iniciais. O histórico é salvo apenas neste navegador.

Modelos sugeridos para começar

Ao selecionar um modelo, o resumo e a descrição são ajustados juntos. O resumo muda automaticamente; só é solicitada confirmação quando a descrição preenchida será substituída. Nada é salvo sem clicar em Salvar atendimento.
